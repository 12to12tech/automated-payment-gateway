    How an order gets marked paid

    1. Each payment link asks for an exact amount. If two unpaid links have the same amount, the newer one gets a few paise added so they differ.
    2. The customer pays. Your bank emails a credit alert to the Gmail inbox above.
    3. The server reads the alert, takes the amount and bank reference, and looks for an unpaid order with that exact amount created in the last 20 minutes.
    4. If one is found, it is marked paid and the customer's page shows the success screen. If not, the alert is listed below as "No order".
